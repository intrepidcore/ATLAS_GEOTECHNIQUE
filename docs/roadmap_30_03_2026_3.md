**Correction 1 — `_parse_float` : remettre `'-'` → `None`**

python

```python
# Dans scripts/utils/amessefe_excel.py
# AVANT (incorrect) :
s = str(val).strip()
if s in ('-', '–', '—', ''):
    return 0.0  # FAUX : '-' = non mesuré, pas zéro

# APRÈS (correct) :
if s in ('-', '–', '—', 'nd', 'n/a', ''):
    return None  # non mesuré → None

# Conséquence : relancer l'import WL/WP après correction
# Les lignes avec WP=None ne seront pas insérées (gate physique)
```

**Correction 2 — Trigger DB pour ip_generated**

sql

```sql
-- À ajouter en migration 167 ou dans la prochaine migration
CREATE OR REPLACE FUNCTION atlas.compute_ip_generated()
RETURNS TRIGGER AS $$
BEGIN
  IF NEW.wl IS NOT NULL AND NEW.wp IS NOT NULL THEN
    NEW.ip_generated := NEW.wl - NEW.wp;
  ELSE
    -- Conserver ip_generated explicitement fourni si wl ou wp manque
    NEW.ip_generated := COALESCE(NEW.ip_generated, NULL);
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_compute_ip_generated
BEFORE INSERT OR UPDATE ON atlas.essais_atterberg
FOR EACH ROW EXECUTE FUNCTION atlas.compute_ip_generated();
```
