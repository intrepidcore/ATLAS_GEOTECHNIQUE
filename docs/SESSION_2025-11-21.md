## 🔧 Corrections techniques

### Problème 1 : Erreur 500 sur `/sondages?missing=geom`
**Cause** : Colonne `code` avec valeurs NULL, modèle Rust attend `String` non optionnel

**Solution** :
1. Remplir tous les codes depuis `meta->>'code'`
2. Générer `AUTO_<id>` pour les orphelins (aucun dans notre cas)
3. Ajouter contrainte `NOT NULL`

### Problème 2 : Références ADM3 incorrectes
**Cause** : Code utilisait `adm3.id` et `adm3.name` (colonnes inexistantes)

**Solution** :
- Utiliser `adm3.gid` (clé primaire)
- Utiliser `adm3.adm3_fr` (nom français)
- Corriger toutes les requêtes SQL
