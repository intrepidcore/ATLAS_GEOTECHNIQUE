# Atlas Géotechnique v0.7.0 - Résumé Exécutif

## 🎯 En bref

**Grille nationale Togo** avec mailles ~2 km², seed multi-villes réaliste, export GeoJSON.

## ⚡ Démarrage rapide (30 secondes)

```bash
docker compose up -d
docker compose exec db psql -U atlas -d atlas -f /docker-entrypoint-initdb.d/007_grid_v0.7.0.sql
docker compose run --rm etl etl load-country
docker compose run --rm etl etl make-grid
docker compose run --rm etl etl load-sample-extended
# Ouvrir http://127.0.0.1:8080
```

## 📋 Ce qui a changé

| Composant | Avant (v0.6.0) | Maintenant (v0.7.0) |
|-----------|----------------|---------------------|
| **Grille** | 5 mailles (Lomé) | 800-1200 mailles (Togo complet) |
| **Aire maille** | Variable (~0.02°×0.02°) | Fixe (~2 km² / 1414m × 1414m) |
| **Sondages** | 12 (zone unique) | 19-31 (4 villes) |
| **Distribution** | Valeurs arbitraires | Gaussiennes + corrélation |
| **UI** | Boutons basiques | + Export GeoJSON |
| **ETL** | 1 commande | 3 commandes (modulaire) |

## 📊 Données générées

- **Mailles** : 800-1200 carrés de ~2 km²
- **Sondages** : 19-31 répartis dans 4 villes
  - Lomé (8-12), Sokodé (4-7), Kara (4-7), Dapaong (3-5)
- **Essais** : 50-100 avec valeurs réalistes
  - SPT_N : 5-50 (gaussienne µ=18, σ=7)
  - qc : 0.5-15 MPa (gaussienne µ=4, σ=2)


## ⚠️ Notes importantes

1. **Migration requise** : Appliquer `007_grid_v0.7.0.sql` avant utilisation
2. **PostGIS 3.1+** : Nécessaire pour `ST_SquareGrid`
3. **Seed reproductible** : Utiliser `--seed 42` pour résultats identiques
4. **Variabilité** : Nombre exact de sondages varie (19-31 selon seed)

## 🐛 Dépannage rapide

| Erreur | Solution |
|--------|----------|
| "table country_tg does not exist" | Appliquer migration 007 |
| "No polygon found in country_tg" | Exécuter `etl load-country` |
| Grille ne s'affiche pas | Exécuter `etl make-grid` |
| 0 mailles avec données | Exécuter `etl load-sample-extended` |
