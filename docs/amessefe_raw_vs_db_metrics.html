Constat critique — structure des types de sol dans le raw

Le fichier raw AMESSEFE organise les données exactement par type pédologique — chaque feuille correspond à un domaine pédologique distinct. C'est la preuve que la stratégie KED par domaine pédologique est alignée avec la structure même de la source de données. Le drift géologique/pédologique n'est pas une hypothèse externe — il est encodé dans l'organisation même du fichier source.
