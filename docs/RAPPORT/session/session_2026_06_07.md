## 2. Nouveaux scripts Python

### A1 — `scripts/validation_bloc_spatial.py`
Validation par 5 blocs latitudinaux N-S (Roberts et al., 2017). 
Corrige l'optimisme du LOO-CV en présence de corrélation spatiale.

**Paramètres** : `--params` (liste), `--horizons`, `--n-blocs`, `--no-kriging`

### A2 — `scripts/validation_picp.py`
PICP (Prediction Interval Coverage Probability) via LOO-CV.
Teste si les intervalles de prédiction ± z×σ sont calibrés.
Avec flag `--log-transform` pour VBS/CBR/EG.

**Paramètres** : `--params`, `--horizons`, `--no-log-transform`

### A8 — `scripts/validation_stationnarite.py`
Indice de Moran I sur les résidus KED + test Levene N/S.
Teste l'hypothèse de stationnarité après dérive hiérarchique.

**Paramètres** : `--params`, `--horizons`, `--bandwidth-km`, `--n-perm`

### P1 — `scripts/sgs_interpolation.py`
Simulation Séquentielle Gaussienne via gstools.
50 réalisations → P10/P50/P90 stockés dans ai_interpolation_values.
Log-transform automatique pour VBS/CBR/EG.

**Paramètres** : `--param`, `--horizon`, `--n-realizations`, `--seed`

### Figures — `scripts/generate_article_figures.py`
Génération des figures article en 300 DPI.
Figures: A4 (PICP), A9 (carte densité), comparaison RMSE, architecture pipeline.
