```typescript
// panel-resize.ts — à créer et importer dans main.ts
export function initPanelResize() {
  const PANELS = [
    { id: 'dashboard', edge: 'right', storageKey: 'atlas-panel-left-w', defaultW: 320, min: 200, max: 500 },
    { id: 'sidebar', edge: 'left', storageKey: 'atlas-panel-right-w', defaultW: 320, min: 200, max: 500 },
  ]

  for (const panel of PANELS) {
    const el = document.getElementById(panel.id) as HTMLElement | null
    if (!el) continue

    const savedW = parseInt(localStorage.getItem(panel.storageKey) || String(panel.defaultW))
    el.style.width = savedW + 'px'

    const handle = document.createElement('div')
    handle.className = 'resize-handle-' + panel.edge
    handle.style.cssText = `
      position:absolute; top:0; ${panel.edge}:0; width:4px; height:100%;
      cursor:ew-resize; background:transparent; z-index:100;
    `
    handle.addEventListener('mouseenter', () => { handle.style.background = '#3B82F620' })
    handle.addEventListener('mouseleave', () => { handle.style.background = 'transparent' })

    let isResizing = false
    let startX = 0
    let startW = 0

    handle.addEventListener('mousedown', (e) => {
      isResizing = true
      startX = e.clientX
      startW = el.offsetWidth
      document.body.style.cursor = 'ew-resize'
      document.body.style.userSelect = 'none'
    })

    document.addEventListener('mousemove', (e) => {
      if (!isResizing) return
      const delta = panel.edge === 'right' ? e.clientX - startX : startX - e.clientX
      const newW = Math.max(panel.min, Math.min(panel.max, startW + delta))
      el.style.width = newW + 'px'
      localStorage.setItem(panel.storageKey, String(newW))
    })

    document.addEventListener('mouseup', () => {
      if (isResizing) {
        isResizing = false
        document.body.style.cursor = ''
        document.body.style.userSelect = ''
      }
    })

    el.style.position = 'relative'
    el.appendChild(handle)
  }
}
```

## Ce que tu dois faire manuellement maintenant

Avant de lancer l'agent, fais ceci directement sur ta machine : ouvre l'explorateur Windows et navigue vers `%LOCALAPPDATA%\IntrepidCore\Atlas`. Tu verras un dossier avec une installation partielle. Supprime ce dossier entier. Ensuite relance le MSI. L'erreur SHA256 disparaîtra parce qu'il n'y a plus d'ancienne installation avec l'ancien SHA en base.

**Bonne pratique supplémentaire :** le diagnostic export que l'installateur Tauri a produit (`manifest.json` avec `postgres_port: null`) te dit que PostgreSQL embarqué n'a jamais démarré — l'erreur SHA256 s'est produite avant même que PG puisse s'initialiser. C'est normal : la vérification d'intégrité du seed se fait au niveau Rust avant d't'entrer dans PG. En supprimant le data dir et en réinstallant proprement, PG démarrera, le seed sera restauré avec le bon SHA256, et `postgres_port` sera un nombre comme `54329` dans le prochain diagnostic.
